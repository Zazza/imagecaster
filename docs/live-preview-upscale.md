# Предпросмотр генерации и увеличение изображения

При поддержке сервером после каждого шага генерации выполняется полное VAE-декодирование промежуточного изображения в разрешении текущего прохода. Показывается последний доступный кадр; быстрые шаги могут пропускаться при опросе. Дополнительное декодирование и PNG-кодирование увеличивают время генерации и потребление памяти. Это текущее состояние изображения, а не окончательный результат оставшихся шагов. При смене стадии последний кадр остаётся до нового; при смене задания, завершении или отмене он убирается.

Кнопки **1080p**, **2K**, **4K** увеличивают изображение из истории или выбранного файла через очередь. Подписи означают длинную сторону **1920**, **2560**, **3840 пикселей**, с сохранением пропорций. Например, портрет 512×768 для 1080p станет 1280×1920. Если исходник уже достиг выбранного размера, увеличение недоступно.

Результат сохраняется новым кадром истории; оригинал остаётся. Используется нейросетевой апскейлер: если он недоступен, задание сообщает ошибку. Для файла очередь сохраняет изображение, выбранное при постановке задания.

Отмена относится к выбранному заданию. Следующее задание очереди продолжает работу; запоздалая отмена предыдущего не должна его остановить.

Для предпросмотра нужен обновлённый бинарник Imagecaster Server и нативный движок с поддержкой декодирования `vae`. Обновление сервера выполняет человек. С сервером без этой поддержки генерация работает без предпросмотра.

Локальные тесты и HTTP fixtures проверяют обмен данными и поведение очереди. Качество предпросмотра, расход памяти и скорость на реальной GPU требуют отдельной живой проверки.

## Настройка процесса
Настройки → Дополнительно → «Показывать процесс генерации» (по умолчанию включено). Отключение сохраняется между запусками и применяется при следующей отправке SD-задания на сервер, включая новые стадии редактирования и Стилиста. Уже выполняющийся native job не меняется. Сервер получает `params.live_preview: false` и использует `preview: none`: без промежуточного VAE decode, с числовыми шагами, остановкой и обычным итоговым изображением. Отсутствующее поле сохраняет прежнее поведение.

Между декодированием, проходами и этапами одного задания последний полученный кадр остаётся на экране до нового. Смена задания, начало/остановка и сброс очищают его; изображение другого задания не подставляется. Во время подготовки временное отсутствие превью не считается отсутствием поддержки сервера.

В Генерации и Стилисте используется общая плавающая панель статуса. Её можно перемещать за заголовок мышью/касанием или стрелками клавиатуры и сворачивать в узкую полоску. В свёрнутом виде доступны процент, полоса прогресса и остановка текущего кадра. Положение и свёрнутость сохраняются при смене этапов и кадров до ухода со страницы; размеры области ограничивают положение панели.
