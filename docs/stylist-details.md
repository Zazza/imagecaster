# Лицо и сохранение исходных деталей в Стилисте

## Настройки лица

В Стилисте откройте «Человек» → дополнительные настройки:

- **Уточнять мелкие лица с LoRA** — дополнительный проход перед подменой лица. По умолчанию выключен: он увеличивает время и может перерисовать лицо или сгладить кожу. Геометрически смещённый результат не вклеивается. Для пресета используются его фактические модель, промпт с LoRA, sampler и остальные параметры, а не настройки другой модели. Для pipeline проход недоступен, поскольку конечная модель заранее не определена этим механизмом.
- **Сила восстановления лица после подмены** — вклад GFPGAN от 0 до 1. Прежнее значение — 0.6. Меньшее значение ослабляет сглаживание, но может сделать заметнее ограничения подмены 128×128; увеличение резкости или сходства не гарантируется. Значение 0 сохраняет результат подмены без вклада восстановителя; само вычисление GFPGAN на текущем сервере при этом не пропускается.

Настройки сохраняются с планом и фиксируются в параметрах задания. Повтор кадра сохраняет его параметры. При правке выбранного кадра сила восстановления наследуется, а дополнительный проход исходной модели не выполняется поверх результата другого редактора: показывается статус пропуска. Старые задания без новых полей сохраняют прежнее поведение.

По статусам кадра видно, был ли дополнительный проход пропущен и почему. Диагностика хранит изображения до примерки, после неё, после принятого дополнительного прохода и после подмены лица. Эти этапы помогают определить, где потерялись детали.

## Татуировки и другие исходные детали

Текст и LoRA не гарантируют точное воспроизведение татуировки. Если её нет уже в базовой генерации, восстановить её из этого кадра нельзя. Новая функция возвращает существующие пиксели, а не придумывает рисунок.

1. Выберите готовый кадр и откройте **«Восстановить детали из исходника»** под ним.
2. Выберите **«До примерки»** для татуировок или **«До подмены лица»** для сравнения обработки лица. Нажмите «Загрузить исходник».
3. Сравните исходник и результат ползунком. При разном размере изображений восстановление запрещено: автоматического растяжения нет.
4. Нажмите «Выделить область» и закрасьте только нужный участок, который находится в том же положении в обоих кадрах. Для татуировок выбирайте кожу, оставшуюся открытой. Не закрашивайте новый рукав или другую одежду, которая теперь закрывает татуировку. Для исправления выделения доступны его undo/redo и «Очистить выделение».
5. Подтвердите совпадение положения области и видимость кожи, затем создайте новый вариант.

Выделенные пиксели копируются из исходника точно, без нейросетевой перерисовки и повторной подмены лица. Все пиксели вне маски остаются от результата. Вариант добавляется в ту же сессию; исходный кадр остаётся. Чтобы вернуться, выберите его.

Это ручная операция для совпадающих областей, а не автоматическое распознавание татуировок или перенос между разными позами. При смене позы, ракурса или расположения участка применять её нельзя. Приложение проверяет размеры и явное подтверждение; визуальное совпадение и видимость кожи подтверждает человек.

Исходники берутся только из приватной локальной диагностики. По умолчанию она хранит последние 10 завершённых кадров (настраивается в «Настройки → Диагностика»); после удаления исходника функция явно сообщает о недоступности. Для старых кадров, сделанных до появления диагностики, исходника нет. Для вариантов приложение ищет исходный диагностический кадр по цепочке связей в пределах той же сессии. При переносе или удалении необходимых кадров восстановление может стать недоступным.

Загрузка и восстановление выполняются внутри приложения. Фото не отправляются в облако, отдельного HTTP-маршрута для диагностических файлов нет. Во время восстановления GPU не используется, LoRA не переобучается. Выделение сбрасывается при смене исходника, результата или этапа сравнения, чтобы его нельзя было случайно применить к другой фотографии.

## Откат

Отключите дополнительный проход, верните силу 0.6 и не применяйте ручное восстановление. Прежний FaceSwap сохраняет прежнее значение. Для отката кода уберите новую панель/RPC и параметры восстановления; схема БД и сервер не менялись.

Режимы записи и очистка теперь управляются постоянным разделом [Настройки → Диагностика](diagnostics.md). Подробные логи и полный набор промежуточных изображений по умолчанию выключены; функциональные исходники для восстановления по умолчанию сохраняются отдельно.
