# Модели и пресеты

Все модели лежат на Imagecaster Server. В приложение встроен каталог моделей со ссылками на скачивание; со страницы **«Каталог»** приложение скачивает их на сервер. Файлы, положенные в папки сервера вручную, тоже используются.

## Типы файлов и куда они ложатся

| Тип | Что это | Папка на сервере |
|---|---|---|
| Модель картинок (checkpoint) | основной файл модели, `.safetensors` или `.gguf` | `models/checkpoints/` |
| Энкодер текста, токенизатор | дополнительные файлы, нужные части моделей | `models/text_encoders/` |
| VAE | декодер изображения для части моделей | `models/vae/` |
| LoRA | небольшие дополнения, меняющие детали или вид | `models/loras/` |
| Апскейлер | модель для увеличения картинок; в каталоге её нет — файл кладётся вручную (`.pth`, `.safetensors`, `.bin`, `.gguf`). Встроены: `lanczos`, `nearest` | `models/upscalers/` |
| Модель ассистента | текстовая модель для промптов или модель, читающая фото | папка текстовых моделей сервера |

Папки указаны относительно папки данных сервера (см. [Установка](setup-ru.md#папка-данных)).

### Как пишется промпт

Ассистент пишет промпт по-разному в зависимости от семейства модели:

- **Обычными фразами** — Flux (1, 2, 3), Z-Image, Moss, Klein, Qwen-Image, Krea, HiDream, Chroma, а также Hunyuan, если добавить его вручную.
- **Тегами через запятую** — все остальные модели (SD 1.5, SDXL, Pony, Anima).

Семейство определяется по имени файла модели.

## Страница «Каталог»

- Три вкладки: «Модели изображений», «Модели ИИ» (модели для промптов и для фото) и «LoRA». У каждой записи виден размер, «Рекомендуется» у отмеченных ★ и «Установлено», если она уже есть на сервере.
- На вкладке моделей изображений есть фильтры: поиск по названию и описанию, семейство, «Скачанные» / «Не скачанные» и «Влезают в N ГБ» — только модели, у которых хотя бы одна версия влезает в видеокарту сервера.
- **Версии.** У модели с версиями есть список «Версия»: у каждой видны размер и сколько примерно нужно видеопамяти, а версии, которые не влезут в видеокарту сервера, помечены. Сначала выбрана самая большая версия, которая влезает (если модель уже скачана — скачанная). Оценка памяти грубая: большая из частей (модель или энкодер текста) плюс VAE плюс 1,5 ГБ на вычисления; на видеокартах меньше 15 ГБ сервер сам раскладывает модель между видеопамятью и обычной памятью, поэтому «не влезет» чаще значит «будет медленно».
- Любая версия сохраняется на сервере под именем модели, поэтому стили работают с любой из них. Скачанная версия определяется по размеру файла; если файл не совпал ни с одной версией (например, старый файл «всё в одном» Z-Image), модель помечена «Скачан другой файл».
- **Заменить на …** появляется, когда выбрана версия, отличная от скачанной: приложение докачивает недостающие доп. файлы, скачивает новую версию и удаляет старый файл (если имя файла совпадает — сначала удаляет, потом скачивает).
- **Скачать** загружает модель вместе с доп. файлами; то, что уже есть на сервере, пропускается. Для моделей со своими пресетами приложение сразу добавляет эти пресеты.
- **Удалить** удаляет модель с сервера.
- **Скачать всё для пресетов** загружает всё, что нужно встроенным пресетам и чего нет на сервере: модели (в версии, которая влезает в видеокарту сервера) с доп. файлами и LoRA. Перед стартом показывает число файлов и общий размер. Та же загрузка предлагается в окне приветствия при первом запуске. Модели, которые встроенные пресеты не используют (Krea 2, Qwen-Image, HiDream-O1, Chroma, FLUX.3 и другие), скачиваются по одной своей кнопкой **Скачать**.

## Пресеты

Пресет (стиль) — готовый набор: промпт, настройки, модель и LoRA. Пресеты приходят вместе со своей моделью:

- Получив список моделей с сервера, приложение добавляет встроенные пресеты тех моделей, что есть на сервере. Имена добавленных пресетов запоминаются, поэтому удалённый пресет не возвращается.
- Пресеты без своей модели или LoRA на сервере скрыты. Флажок «Показать пресеты без моделей» на странице «Стили» показывает их.
- Если сервер не вернул список моделей, ничего не скрывается.

### Правка через Qwen-Image

Если Qwen-Image 2.1 есть на сервере, в карточке «Правка» появляется выбор модели: Flux.2 Klein (по умолчанию, быстро) или Qwen-Image (медленнее, строже держит лицо и детали одежды, свет площе). Для правки Qwen нужен модуль зрения `mmproj-Qwen3VL-8B-Instruct-F16.gguf`, каталог скачивает его вместе с моделью. Эффекты Qwen показываются в карточке «Эффект» рядом с эффектами Klein, с пометкой «(Qwen-Image)». «Описать образ» и инструменты для ИИ-агентов остаются на Klein.
