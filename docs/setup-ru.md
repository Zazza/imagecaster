# Imagecaster — настройка

Imagecaster работает только через [Imagecaster Server](https://github.com/Zazza/imagecaster-server). Сервер ставится на компьютер с видеокартой: сам ставит движок картинок (sd.cpp) и движок текста (llama.cpp), запускает их, скачивает модели из каталога приложения и пропускает все запросы к видеокарте через одну очередь, чтобы хватало памяти.

## Установка сервера

Скачайте архив для своей системы со страницы [Releases](https://github.com/Zazza/imagecaster-server/releases), распакуйте и запустите. Нужна видеокарта NVIDIA со свежим драйвером.

Установка по шагам для Windows, Linux и macOS, настройки и API — в [README сервера](https://github.com/Zazza/imagecaster-server/blob/main/README-ru.md) и [полной документации](https://github.com/Zazza/imagecaster-server/blob/main/docs/server-ru.md).

Обновление со старого сервера на Forge и Ollama: сервер сам переходит на новые движки, скачанные модели остаются.

## Подключение приложения

При запуске Imagecaster проверяет сервер:

- **Сервер найден** — приложение открывается как обычно.
- **Сервер не найден** — окно ищет сервер в локальной сети (mDNS), даёт ввести адрес (`http://192.168.1.100:8080`) и ведёт на инструкцию по установке.
- **Сервер устарел** — окно ведёт на инструкцию по обновлению. Старые серверы не сообщают о возможностях, которые нужны приложению.

Окно можно закрыть: приложение откроется в ограниченном режиме с полосой сверху. Библиотека, история и настройки работают; генерация, правка и составление промптов ждут сервер. Кнопка на полосе снова открывает проверку.

Адрес меняется и в «Настройки» → «Подключение».

Обновление с версии приложения, которая подключалась к Forge и Ollama напрямую: при первом запуске приложение ищет сервер на компьютере, где работали Forge или Ollama (порт 8080), и подключается к нему, если нашло.
