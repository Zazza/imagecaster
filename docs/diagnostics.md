# Постоянная диагностика приложения

Раздел находится в **Настройки → Диагностика**. Настройки сохраняются между запусками; для переключения режима перезапуск не нужен.

## Три независимые настройки

- **Подробные логи**, по умолчанию выключены. Включают строки `generation_sd` со временем этапов и подробные решения MemoryGuard о памяти. При выключении обычные ошибки и предупреждения остаются. Генерация, исправленная выгрузка LLM и параметры качества от этого переключателя не зависят. Проверка анатомии также является отдельной рабочей функцией, а не частью отладки.
- **Промежуточные изображения**, по умолчанию выключены. Сохраняют полный набор этапов Стилиста: base, garment, face-pass, face-swap. Пропущенного или неудачного этапа в наборе нет.
- **Исходники для восстановления деталей**, по умолчанию включены. Сохраняют рабочие источники base/garment/face-pass для функции «Восстановить детали из исходника». Поэтому выключение отладки само по себе эту функцию не ломает. Итоговый face-swap без полной диагностики дополнительно не сохраняется.

Если выключены оба вида сохранения изображений, новые диагностические файлы не создаются. Уже сохранённые файлы не удаляются при переключении; существующие источники по-прежнему можно использовать, пока они не удалены или не вытеснены лимитом. Если включена полная диагностика, её кадры также могут служить источниками восстановления.

Запись каждого кадра получает снимок настроек при начале записи. Изменение режима или лимита не меняет уже активный регистратор. Логи также сохраняют выбранный режим на весь начатый этап, чтобы строка начала не потеряла соответствующую строку окончания.

## Хранение

Можно выбрать от 1 до 50 завершённых кадров, по умолчанию 10. После завершения нового кадра старые записи удаляются до лимита, выбранного при старте его записи. Текущие записи и незавершённые остатки после аварии могут увеличивать общее число каталогов сверх этого лимита.

В разделе показаны путь, размер файлов, число каталогов, активные записи и незавершённые остатки. «Обновить» перечитывает состояние. «Открыть папку» открывает только выделенную локальную папку `stylist-diagnostics` рядом с базой приложения; произвольный путь через этот API передать нельзя.

«Очистить диагностику» требует отдельного подтверждения. Она удаляет также сохранённые исходники для восстановления деталей. Основная история, готовые снимки и пользовательские фотографии вне этого кэша остаются. Пока идёт запись кадра, очистка запрещена. Символические ссылки и неизвестные файлы не удаляются; при их обнаружении операция отказывается от очистки.

Файлы хранятся локально, с приватными правами Unix 0700/0600. В Windows действуют разрешения файловой системы. Новых HTTP-маршрутов, загрузки в облако или просмотра личных фотографий для диагностики нет. Кэш рассчитан на один процесс приложения: не очищайте общее хранилище при работе другого экземпляра с той же базой.

## Логи

Подробные записи находятся в существующей панели «Логи»: время txt2img/img2img/upscale/faceswap и снимки памяти, когда они доступны в MemoryGuard. Они не добавляют сетевых опросов. В новых строках этапов нет промптов, изображений, имён людей или LoRA. Обычные сообщения остального приложения этим режимом не фильтруются.

Используется прежний журнал последних 500 записей в памяти, отдельный файл логов на диске не создаётся. Если воспроизвели замедление, сохраните нужные строки до перезапуска. Время этапа включает ожидание ответа сервера, загрузку модели и работу; оно не доказывает перегрев или причину артефактов.

## Откат

Выключите подробные логи и промежуточные изображения. При необходимости выключите сохранение рабочих исходников; существующие файлы удаляются отдельно подтверждённой очисткой. Исправление управления памятью продолжает работать. Схема БД и сервер не менялись, новые значения находятся в существующих settings.
