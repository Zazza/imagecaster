# Выделение объекта для эффектов

В Постобработке → Эффекты включите «Выделить область». В режиме «Кисть с определением границ» закрасьте только ту часть, которую хотите изменить: например, два рукава без середины рубашки. «Закрасить» добавляет область, «Стереть» убирает лишнее. Мазки и их отмена не запускают модель.

Нажмите «Определить границы». Итоговое выделение — пересечение ваших мазков и найденного предмета. Оно никогда не расширяется на всю вещь. Проверьте белую маску и примените эффект. После изменения мазков нужно ещё раз определить границы. Исходное закрашивание сохраняется независимо от очищенного результата: повторное определение может восстановить ранее отрезанные части.

Для этой маски применяется строгая композиция: вне неё остаются исходные пиксели, включая прозрачность. Внешней растушёвки нет. Поэтому грубо обрезанный поперёк ткани мазок может дать заметный стык материала. Для буквального закрашивания без модели выберите «Точная кисть»; этот режим сохраняет прежнюю мягкую композицию. Без выделения эффект работает как раньше на всём кадре.

## Волшебная палочка

Третий режим выбирается в том же списке. Кликните по предмету: локальная модель попробует выделить область целиком. Следующий обычный клик заменит выделение. Shift+клик добавит независимо найденную область к предыдущей. Движение мыши с нажатой кнопкой не запускает новые поиски: точка берётся в момент нажатия.

Каждая область определяется отдельно, затем маски объединяются по пикселям. Быстрые добавления выполняются последовательно. Более новый обычный клик отменяет принятие старых результатов. Пока поиск идёт или завершился ошибкой, применить эффект нельзя. Для исправления доступны отдельные кнопки отмены/повтора выделения и очистка маски. Общие Undo/Redo по-прежнему относятся только к обработке кадра.

Размер кисти и кнопка ручного определения в этом режиме не используются. В отличие от кисти с определением границ, палочка может расширить выделение на весь найденный предмет. Проверьте маску: модель может выбрать человека вместо отдельной детали. Строгая композиция сохраняет все пиксели за пределами готовой маски.

При первом определении границ или первом клике палочкой приложение скачивает около 45 МБ весов в `object-mask` рядом с базой приложения. После этого сегментация работает без сети на CPU. Фото не отправляется за пределы компьютера; обработку эффекта выполняет настроенный локальный сервер. Неудавшуюся загрузку можно повторить той же кнопкой.

На тестовом CPU в ORT WASM с одним потоком подготовка изображения Ады 1024×1536 заняла 4,3 с, уточнение маски — 0,3–0,4 с. Это замер этого компьютера, а не гарантия скорости. Модель может выбрать человека вместо одежды или пропустить деталь. Пересечение ограничивает область изменений, но не гарантирует правильное распознавание ткани: просмотрите результат. Выделение до 32 мегапикселей; в пакетном режиме маски нет.

## Зависимости и происхождение

- [MobileSAM](https://github.com/ChaoningZhang/MobileSAM), Apache 2.0; encoder ONNX из [Akbartus/projects](https://huggingface.co/spaces/Akbartus/projects/tree/e1813cbdd878bf0037e0e81a08c5e93fe31d66e7).
- Decoder из [MobileSAM-in-the-Browser](https://github.com/akbartus/MobileSAM-in-the-Browser/tree/fa8e7b9215ccdc45e8a5f5b8a42892ad4b440e1f), экспорт [Segment Anything](https://github.com/facebookresearch/segment-anything), Apache 2.0. Веса не включены в репозиторий/сборку, URL и SHA-256 зафиксированы в `internal/objectmask/store.go`.
- [ONNX Runtime Web](https://github.com/microsoft/onnxruntime), MIT, версия 1.31.1. Matching WASM/mjs включены в сборку Vite локально. Текст лицензии: `frontend/public/third-party/onnxruntime-LICENSE.txt`.
